# Anhang 5: Änderungen von Dokumenten und Spezifikationen

Gemäß [§29](../bylaws.md#29) Absatz (1) wird hiermit festgelegt:
- Bis zur Veröffentlichung von Version 2.0.0 der AddonScript Spezifikation können
Änderungen an dieser durch tilera beschlossen werden
- Bis zur Veröffentlichung des Anvilcraft Document Registry können Änderungen
an dessen Inhalten durch tilera beschlossen werden
- Änderungen an diesem Anhang der Satzung können durch tilera beschlossen werden,
sofern diese Änderungen keine Regelungen enthalten, die über AddonScript und das 
Anvilcraft Document Registry hinaus gehen
